# 등거리 조립 솔버 — ARAP + 굽힘, 해석해 2케이스 검증

평면 패널을 봉제선으로 이어 붙였을 때 **늘어나지 않으면서 가장 덜 구부러진** 3D 형태를 구한다.
중력·몸·충돌·동역학 없음. 정적 최소화 한 번이고 **봉제 제약만이 변형을 구동한다.**

```
python run_case1.py            # 직사각형 -> 원통    simulationresult1.ply,  ..._nobend.ply
python run_case2.py            # 부채꼴  -> 원뿔     simulationresult2.ply,  ..._nobend.ply
python run_case1.py --seam-hinges   # 진단 실행 (아래 "어긋난 것 1")
python run_case2.py --seam-hinges
python run_case1.py --sweep    # lambda_b 스윕
python verify.py               # 5절 검증 전부 + 4.1 결론표
python render.py               # result/*.ply -> PNG
```

실행 환경: Python 3.10 / numpy 2.2.6 / scipy 1.15.3. **scipy는 선택** — 없으면 dense 경로로
자동 전환한다(`arap.HAVE_SCIPY`).

## 0. 먼저 — 예상과 어긋난 것 (지시서 §7.4)

### 어긋난 것 1 — §1.5(봉제선 가로지르는 엣지를 굽힘에서 제외)가 케이스 1의 해석해를 막는다

지시서의 근거는 "봉제선을 가로지르는 엣지는 rest 이면각이 정의되지 않는다"이다.
**일반적인 봉제선에는 맞지만 이 두 케이스에는 틀리다.** 케이스 1의 봉제는 `x=0` 변과 `x=W`
변을 같은 `y`끼리 잇는데, 두 경계열의 rest 엣지 길이가 **정확히 같다.** 따라서 rest 평면은
봉제선을 가로질러 **평행이동 `-W`로 등거리 연장**된다 — 이면각은 정의되고, 평평하다.
케이스 2도 마찬가지로 `-2π/3` 회전으로 연장된다.

제외하면 봉제선에서의 **꺾임에 벌점이 0**이 된다. 그러면 원이 답이 아니다: 닫힌 곡선의
`∫κ²ds ≥ (∫κ ds)²/L`인데 꺾임각 `θ`가 총 회전량을 흡수해 매끄러운 부분은 `2π−θ`만 돌면 되므로
하한이 내려간다. 실제로 그렇게 간다:

| | 봉제 힌지 제외 (지시서 §1.5) | 봉제 힌지 포함 (진단) |
|---|---|---|
| 봉제선에서의 회전각 | **102.05°** | **5.609°** |
| 나머지 정점의 회전각(균일값) | 5.625° | 5.625° |
| 반지름 | 0.962547 ± 0.159486 | **1.000215 ± 0.010966** |
| `E_bend` | 53.38 | 75.34 |

이게 **수렴 부족이 아니라 진짜 최소점**이라는 증거 — 반복을 늘리면 꺾임이 **커진다**:

| 반복 | 500 | 2000 | 8000 |
|---|---|---|---|
| 봉제선 회전각 | 49.1° | 83.0° | 100.1° |
| `E_bend` | 60.88 | 54.09 | 52.94 |

`E_bend`가 단조 감소하면서 꺾임이 자란다. 티어드롭이 원보다 에너지가 낮다.

> **파라미터를 맞춰 통과시키지 않았다(§8).** 지시서대로 제외한 결과를 1차 산출물로 두고,
> 이면각이 실제로 정의된다는 근거로 포함한 실행을 `_seamhinge` 접미사로 **따로** 냈다.

### 어긋난 것 2 — 평면 초기값에서 고정 `λ_b`는 수렴하지 않는다. `λ_b` 연속법이 필요하다

지시서에 없는 항목이다. 평면 + 난수 z 섭동에서 출발하면 작은 `λ_b`로는 원통이 안 나온다.
시트가 너무 물러서 봉제선이 닫히는 동안 **납작하게 접힌다**(단면 winding number **0**).

진단 지표로 단면 다각형의 **winding number**를 넣었다(`arap.winding_number`). 1이면 관 하나,
0이면 접힘, 2면 두 번 말림. 이게 없으면 "구겨졌다"와 "접혔다"를 구분할 수 없다.

해법: `w_s`와 똑같은 방식으로 **`λ_b`를 뻣뻣함 → 목표값으로 어닐링**한다. 뻣뻣한 시트가
장파장(관 하나) 모드를 고르고, 그다음 물러지면서 `λ_b` 편향이 제거된다.

| `λ_b` 스케줄 (평면 초기값, 32×16) | winding | 반지름 | max\|σ−1\| |
|---|---|---|---|
| 1e-4 고정 | **0.000** | 0.4007 | 9.7e-2 |
| 1e-2 고정 | −1.000 | 0.9733 | 4.6e-2 |
| 1e-1 고정 | 1.000 | 0.8069 | 2.2e-1 |
| **1e-1 → 1e-2 → … (어닐링)** | **−1.000** | **1.000610** | **5.6e-4** |
| 1e-2 → 1e-3 → 1e-4 | 0.000 | 0.7321 | 6.2e-3 |

어닐링 시작점이 1e-1이어야 한다 — 1e-2에서 시작하면 접힌다.

**답이 초기값에서 오지 않는다는 증거**: 잡음 종류(백색/저역통과), 진폭(0.01W/0.001W),
`w_s` 시작값(1e-2/1e-6)을 바꿔도 결과가 **완전히 동일**했다 (1.000610 / 2.177e-2 / 5.62e-4).

### 어긋난 것 3 — §1.8("한 번만 분해")과 §1.9(연속법)은 문자 그대로 양립 불가

`w_s`가 `L` 안에 있으므로 `w_s`를 바꾸면 `L`이 바뀐다. 재분해 없이 푸는 방법이 있다.
봉제 항의 행렬은 `S = DᵀD`이고 `D`는 `(#pairs × N)` — 랭크가 33(케이스 1), 40(케이스 2)뿐이다.
**Woodbury**로 흡수한다:

```
(L0 + w_s DᵀD)⁻¹ = L0⁻¹ − L0⁻¹Dᵀ (I/w_s + D L0⁻¹Dᵀ)⁻¹ D L0⁻¹
```

`Y = L0⁻¹Dᵀ`와 `C = DY`를 처음에 한 번만 만들면, 이후 **모든 `w_s`가 33×33(또는 40×40)
작은 풀이 하나로 공짜다.** 반복당 재분해는 **0회**다. 검증: `w_s = 1e-2, 1, 1e4`에서
Woodbury 해의 상대 잔차 `1e-15`(dense 직접 풀이와 동일).

남는 분해는 `λ_b`당 1회뿐이다 (`λ_b`는 `L0` 안에 있다) — 사다리가 8단이므로 두 케이스 모두 8회.
**반복당이 아니라 실행 전체에서** 8회다 (반복 2000~2800회 동안).

### 어긋난 것 4 — §4.2의 예상이 틀렸다. `λ_b`의 절대값은 최소점을 **움직인다**

지시서는 "하드 제약 아래에서는 `λ_b`가 최소점 위치에 영향을 주지 않아야 한다"고 했다.
ARAP은 **소프트 벌점**이므로 영향을 준다 — 지시서가 단 조건("영향을 준다면 등거리가 사실상
소프트하게 걸려 있다는 뜻")이 바로 이 경우다. 양을 유도했다.

반지름 `r`인 원통에서 원주 방향 신축률은 `σ₁ = r`이므로
`E_ARAP = (rest 면적)·(r−1)² = 8π(r−1)²`.
2차 굽힘 모델은 rest 계량으로 `‖∂²p/∂u²‖²`를 재므로 `E_bend = 3·r²·2πH`
(등거리일 때만 `∫κ²dA`와 일치한다 — 늘어나면 `r³`배 과벌점).
합을 최소화하면

```
r*(λ_b) = R_poly / (1 + 3 λ_b)
```

측정(32×16, 봉제 힌지 포함):

| `λ_b` | 예측 `R_poly/(1+3λ_b)` | 측정 | 차이 |
|---|---|---|---|
| 1e-4 | 1.001308 | 1.001307 | 8.0e-7 |
| 1e-5 | 1.001578 | 1.001577 | 1.1e-6 |
| 1e-6 | 1.001605 | 1.001604 | 1.2e-6 |

유효숫자 4자리로 일치한다. 따라서 `|r−1| < 1e-3`이려면 `3λ_b < 1e-3`, 즉 `λ_b ≲ 3e-4`.
실제로 쓴 값은 두 케이스 공통으로 `λ_b = 1e-8`이라 이 편향은 `3e-8`로 무시할 수준이다
(케이스 2의 꼭짓점 조건이 더 빡빡해서 사다리 끝을 거기에 맞췄고, **그 값을 케이스 1에도 그대로
썼다** — 케이스 1의 `max|σ−1|`은 오히려 `1e-4`일 때의 3.3e-3에서 1.55e-4로 좋아졌다).

### 어긋난 것 5 — 반지름 `1.000000`은 이산 메시에서 **도달 불가능**하다

등거리는 엣지 **길이**를 보존한다. 봉제된 단면은 변 길이 `W/nw`인 정 `nw`각형이므로
외접원 반지름은

```
R_poly = (π/nw) / sin(π/nw) = 1 + (π/nw)²/6 + ...
```

`nw=64`에서 **1.000402**, `nw=32`에서 1.001608. 즉 지시서의 합격선 `1.0 ± 1e-3`은
`nw=64`에서 **이미 +4.0e-4를 소모한 채** 시작한다. `nw=32`였다면 이산화만으로 불합격이다.
`verify.py`가 이 값을 같이 출력한다.

### 어긋난 것 6 — 케이스 2 꼭짓점에서 굽힘/신축 강성비가 발산한다

Bergou 가중치는 `w_e = 3/A_e`, ARAP 가중치는 `A_t`다. 꼭짓점으로 갈수록 `A → 0`이므로
**둘이 반대 방향으로 발산**하고 비는 `1/A²`로 커진다. 실측(nr=20): `max(w_e)/min(A_t) = 1.6e6`.
그래서 `max|σ−1|`은 꼭짓점 값이고 거의 전적으로 `λ_b`가 정한다:

| `λ_b` | 1e-4 | 1e-5 | 1e-6 | 1e-7 | 1e-8 | 1e-9 |
|---|---|---|---|---|---|---|
| `max\|σ−1\|` (전체) | 7.3e-2 | 2.8e-2 | 5.3e-3 | 3.9e-3 | **7.0e-4** | 4.7e-4 |
| `max\|σ−1\|` (꼭짓점 밖) | 2.9e-3 | 3.0e-4 | 4.2e-5 | 2.0e-4 | 1.9e-4 | 2.0e-4 |

`max|σ−1|`이 합격선 `1e-3` 아래로 내려가는 가장 큰 `λ_b`가 **1e-8**이다.
두 케이스 중 이 조건이 더 빡빡한 쪽이 케이스 2이므로 사다리 끝을 1e-8로 정하고,
**케이스 1에도 같은 값을 쓴다.** 케이스별로 다른 값을 쓰지 않는다.

지시서 §3.5는 꼭짓점 **에너지**의 로그 발산을 경고했는데, 실제 영향은 **형태**에도 온다.
`verify.py`는 그래서 `max|σ−1|`과 함께 `p50`, `p99.9`를 같이 낸다.

### 어긋난 것 7 — 500 반복으로는 부족하다

지시서 §1.8의 상한은 500이다. 실제 필요한 반복 수는 케이스 1이 2780, 케이스 2가 2716이었다
(`λ_b` 어닐링 8단을 합친 값). 각 단계 안에서는 상대 에너지 변화 `< 1e-10`으로
종료하며, 스테이지 하나가 500을 넘는 일은 없다.

### 어긋난 것 8 — Bergou 정규화의 상수는 3이다

`w_e = 3/A_e`로 두면 연속체 극한에서 `E_bend → 3·∫(κ₁²+κ₂²) dA`다. 반지름 `r`, 높이 `H`인
원통으로 확인(연속체 값 `2πH/r`):

| `nu` | 32 | 64 | 128 | 256 |
|---|---|---|---|---|
| `E_bend / (2πH/r)` | 2.8876 | 2.9484 | 2.9754 | **2.9880** |

`r=1`과 `r=2`에서 비가 완전히 동일 — `1/r` 스케일링도 정확하다. 상수 3은 `λ_b`를 되스케일할
뿐이라 결론에 영향이 없지만, 다른 문헌 값과 비교하려면 알아야 한다.

## 1. 수식 — 구현된 그대로

### 1.1 변형 그래디언트 (삼각형마다 독립)

삼각형 `t = (i,j,k)`, rest 평면 좌표 `x ∈ R²`, 구하는 3D 위치 `p ∈ R³`:

```
E_t = [x_j−x_i, x_k−x_i] ∈ R^{2×2}      P_t = [p_j−p_i, p_k−p_i] ∈ R^{3×2}
F_t = P_t E_t⁻¹ ∈ R^{3×2}
```

구현은 이걸 **정점마다의 상수 벡터**로 다시 쓴다 (`arap.shape_gradients`):

```
F_t = Σ_{v∈t} p_v g_vᵀ ,   g_j = (E_t⁻¹)[0,:],  g_k = (E_t⁻¹)[1,:],  g_i = −(g_j+g_k)
```

이 형태라야 `p`에 대한 2차형식으로 바로 조립된다. 검증: 소박한 `P_t E_t⁻¹`와 `6.7e-16` 일치.

### 1.2 ARAP 에너지와 local step

```
E_ARAP = Σ_t A_t ‖F_t − R_t‖²_F ,   R_t ∈ R^{3×2},  R_tᵀR_t = I₂
```

`R_t`는 **삼각형마다 자유로운 회전**이다. 정점 1-링을 쓰지 않는 이유(§1.4): 봉합된 정점의
1-링은 각 결손 때문에 평면에 눕지 않아 rest 위치를 `R²`에 정의할 수 없다. 삼각형은 언제나
평면이다.

thin SVD `F = U Σ Vᵀ` (`U ∈ R^{3×2}`)에서 `R_t = U Vᵀ`.

> **행렬식 보정을 하면 안 된다.** 3×3 ARAP의 "det < 0이면 최소 특이값 부호를 뒤집는다"는
> `SO(3) ⊂ O(3)`가 비연결이라서 필요한 것이다. 여기 제약집합은 슈티펠 다양체 `V₂(R³)`이고
> **연결되어 있다.** 검증: 무작위 `R ∈ V₂(R³)` 4000개를 대입해도 `UVᵀ`보다 나은 게 하나도
> 없었다(최소 마진 0.000e+00).

**항등식** (`verify.py`가 assert):

```
‖F_t − R_t‖²_F = (σ₁−1)² + (σ₂−1)²
```

실측 오차 `5.6e-16`(합성 테스트), `1.4e-17`~`5.0e-17`(실제 결과). ⇒ **ARAP은 신축률만의
함수이고 곡률은 식에 등장하지 않는다.**

### 1.3 굽힘 — Bergou et al. 2006 2차 모델 (rest 평면이라 정확)

내부 엣지 `e`의 4정점 `(x₀,x₁ = 공유 엣지, x₂, x₃ = 각 삼각형의 마주보는 정점)`:

```
c₀₁ = cot∠(x₀ 에서, 삼각형 x₀x₁x₂)      c₀₂ = cot∠(x₀ 에서, 삼각형 x₀x₁x₃)
c₀₃ = cot∠(x₁ 에서, 삼각형 x₀x₁x₂)      c₀₄ = cot∠(x₁ 에서, 삼각형 x₀x₁x₃)

K_e = ( c₀₃+c₀₄ ,  c₀₁+c₀₂ ,  −c₀₁−c₀₃ ,  −c₀₂−c₀₄ )
w_e = 3 / (두 삼각형 넓이의 합)
E_bend = Σ_e w_e ‖K_e · p‖²
```

`K_e`의 정체는 **평면 위 네 점의 아핀 종속 관계**다: `Σ K_i = 0`이고 `Σ K_i x_i = 0`.
평면의 네 점은 1차원 아핀 종속을 가지므로 `K`는 상수배를 빼면 유일하고, cot 공식이 그 상수배를
정한다. 검증: 무작위(바늘형 포함) 유효 힌지 5000개에서 cot 공식과
`[[1,1,1,1],[x₀,x₁,x₂,x₃]]`의 SVD 영공간이 **1.3e-13** 일치.

`K`가 rest의 모든 아핀상을 소멸시키므로 평면·강체운동·균등축소 상태에서 에너지가
정확히 0이다(실측 `1e-28`).

### 1.4 봉제 항과 전체 에너지

```
E_stitch = Σ_(a,b) ‖p_a − p_b‖²          (짝지어진 정점은 병합하지 않는다)
E        = E_ARAP + λ_b·E_bend + w_s·E_stitch
```

지시서 §1.6/§1.7은 `w_s`를 두 번 쓰는데, 여기서는 `E_stitch`를 가중치 없이 정의하고
총합에서 한 번만 곱한다.

### 1.5 local / global 교대

**global step**: `{R_t}` 고정 → `E`가 `p`에 대해 2차 → `L p = b`.

```
L(w_s) = K_cot + λ_b H_bend + ε I + w_s DᵀD
K_cot[u,v] = Σ_t A_t (g_u·g_v)            (= 평면 rest 메시의 코탄젠트 라플라시안)
b[v]       = Σ_t A_t R_t g_v ∈ R³
```

`K_cot`이 코탄젠트 라플라시안과 같다는 것을 독립 구현과 대조: **오차 0.000e+00**.
스칼라 `N×N` 행렬 하나를 3개 좌표열에 각각 적용한다(3N×3N 아님).

평행이동 3자유도는 `ε I` (`ε = 1e-8 × 평균 대각)로 제거하고, 매 반복 후 중심을 0으로 맞춘다
— 세 에너지 모두 평행이동 불변이라 형태에 영향이 없고 게이지만 고정한다.
`b`는 `Σ_v g_v = 0`이므로 상수벡터와 직교한다(평행이동 성분 0).

**단조성**: 두 스텝 모두 고정 가중치에서의 정확한 최소화이므로 `E`는 **스테이지 안에서**
증가하지 않는다. 스테이지 경계에서는 `w_s`(또는 `λ_b`)가 방금 커졌으므로 `E`가 튄다 — 버그가
아니다. `verify.py`는 스테이지 안에서만 검사한다. **6개 실행 전부 위반 0회.**

### 3.1 추정기 자체의 정확도

해석해로 초기화하거나 시드하지 않았음을 보장하기 위해 추정기를 **합성 정답 메시**로 따로
검증했다.

- **원뿔**: 대수 잔차 `(p−a)·n − |p−a|cosβ`를 최소화하는 통상적 적합은 **쓸 수 없다** —
  꼭짓점을 무한대로 보내면 모든 잔차가 0이 되어 `sinβ → 0`으로 붕괴한다(실측: 참값 1/3에
  대해 2.3e-5를 반환). 대신 두 가지 닫힌형 추정기를 쓴다.
  (a) 원뿔의 모든 단위 법선은 꼭짓점과 무관하게 `N·axis = −sinβ`를 **정확히** 만족한다 →
  축 = 법선 공분산의 최소 분산 방향, `sinβ = |mean(N·axis)|`.
  (b) 축이 정해지면 단면 반지름이 축 좌표의 1차 함수 `ρ(t) = tanβ·(t − t_apex)` → 직선 적합.
  임의 자세의 정확한 원뿔 메시에서 오차: (a) 6.2e-4, (b) **1.2e-4**. 원통에 넣으면
  `sinβ = 3e-16`으로 올바르게 퇴화한다.
- **원통 축**: 지시서대로 PCA를 쓰되 법선 공분산 영방향을 교차검증으로 같이 낸다
  (실측 차이 0.0010°). PCA는 종횡비에 의존한다 — 축 방향 분산 `H²/12 = 1.333`이 반경 방향
  `r²/2 = 0.5`보다 커야 하는데, `H/r < √6 ≈ 2.449`면 **조용히 뒤집힌다.** 여기선 `H/r = 4`라
  안전하지만 재사용 시 함정이다.

동점은 다른 곳에 있고, 훨씬 깨끗하다 — **같은 `λ_b`로 얻은 티어드롭과 원통 쌍**이다:

| | `result1` (티어드롭) | `result1_seamhinge` (원통) |

등거리 판정만으로는 **둘을 구별할 방법이 전혀 없다.** 그런데 형태는 완전히 다르다.

`λ_b = 0` 행은 그 극단이다: 형태를 고를 항이 아예 없으니 최소점이 유일하지 않고,

⇒ **등거리만으로는 형태가 정해지지 않는다. 굽힘이 형태를 고른다.**

### 부채꼴 메시의 꼭짓점 처리

`r = 0`은 정점 **하나**(인덱스 0)로 축약하고 첫 링은 부채꼴 삼각형으로 만든다 — 넓이 0인
삼각형이 없어야 `E_t`가 가역이다. 실측 최소 rest 넓이 `1.227e-4` (최대 `4.907e-3`).
꼭짓점은 이미 공유 정점이므로 봉제 짝에서 제외한다(40쌍, `r`만 짝지음).
두 메시 모두 전 삼각형 넓이가 양수 — 방향(winding)이 일관된다.
